# سلّتي

## 1) نشر الموقع (مجاني) – يشتغل كتطبيق على أندرويد
1. أنشئ مستودعاً عاماً جديداً على github.com، وارفع كل محتويات هذا المجلد (اسحب المجلد كاملاً بما فيه `.github`).
2. من Settings ← Pages ← Source اختر **GitHub Actions**.
3. بعد دقيقة يظهر الرابط في تبويب Actions. افتحه بكروم على أندرويد ← القائمة ← "تثبيت التطبيق".

## 2) بناء ملف APK (اختياري)
1. تبويب Actions ← **Build APK** ← Run workflow.
2. بعد انتهائه، نزّل **salati-apk** من أسفل صفحة التشغيل (ملف مضغوط فيه app-debug.apk).
3. فك الضغط وثبّت الملف على الجهاز (فعّل التثبيت من مصدر غير معروف).

## تعديل التطبيق
كل الكود في `www/index.html`. أي تعديل + Commit بينشر الموقع تلقائياً.
